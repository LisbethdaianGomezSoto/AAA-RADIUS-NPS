# 🛠️ Scripts

| Carpeta | Contenido | Cómo se usa |
|---|---|---|
| [`windows/`](windows/) | PowerShell del Windows Server, numerados en el orden de ejecución | Abrir PowerShell **como administrador** en `W-Server` y ejecutar cada bloque |
| [`cisco/`](cisco/) | Comandos aplicados en R1 y SW-1, divididos en bloques | Pegar por la consola de GNS3, bloque por bloque |

**Orden recomendado:** `01` → `02` → `03` → `04` (y las políticas de red en `nps.msc`) → R1 → SW-1 → `05-verificacion.ps1`.
